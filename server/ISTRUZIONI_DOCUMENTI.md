# Documenti PDF sul server

Carica la cartella `egypt_data/documents/` sul sito:

```
egypt_data/
  documents/
    boarding/
      boarding_kcf55qh.pdf
      boarding_kcm257j.pdf
    insurance/
      certificato_assicurativo.pdf
      set_informativo.pdf
      informativa_precontrattuale.pdf
```

Aggiorna anche `egypt_data/config.json` (sezione `documents` con gli URL).

I PDF sono già **incorporati nell'app** (funzionano offline). Gli URL sul server servono come backup e per aggiornamenti senza reinstallare l'APK.

Verifica URL nel browser, es.:
`https://www.fr-italy.com/egypt_data/documents/boarding/boarding_kcf55qh.pdf`
